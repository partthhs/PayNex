# PayNex

> **Intelligent Shopping. Seamless Payments.**

PayNex is an AI-powered intelligent shopping and payment platform.

---

## Project Structure

```
PayNex/
├── frontend/     React + Vite + Tailwind CSS application
├── backend/      Python FastAPI application (Phase 2)
└── README.md
```

## Tech Stack

| Layer     | Technology                  |
|-----------|-----------------------------|
| Frontend  | React 19, Vite 8, Tailwind CSS v4 |
| Routing   | React Router DOM v7         |
| Animation | Framer Motion               |
| Icons     | Lucide React                |
| HTTP      | Axios                       |
| Backend   | Python FastAPI (Phase 2)    |
| Database  | Supabase PostgreSQL (Phase 2)|
| AI        | Gemini API (Phase 2)        |
| Payments  | PayPal Orders API (Phase 2) |

---

## Getting Started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

The app will be available at `http://localhost:5173`.
